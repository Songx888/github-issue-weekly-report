# GitHub 自动周报部署服务

## 一句话介绍

我帮你把 GitHub Issues 和 Pull Requests 自动整理成每周项目周报，适合小团队、外包项目、远程协作团队和开源项目维护者。

## 适合谁

- 每周都要给客户、老板或团队写项目进度的人
- 用 GitHub Issues 管理任务，但周报还靠手工复制的人
- 外包团队需要把开发进度整理成客户能看懂的格式
- 开源项目维护者想自动整理本周完成、进行中和阻塞事项

## 交付流程

1. 你提供 GitHub 仓库地址和现有标签规则。
2. 我先免费判断是否适合自动化。
3. 确认套餐后，我配置工具和 GitHub Actions。
4. 交付第一份周报样例。
5. 你确认格式后，我补充部署说明和后续维护边界。

## 我需要你提供什么

- GitHub 仓库地址
- 仓库是公开还是私有
- 哪些标签代表已完成、进行中、阻塞
- 周报生成时间，例如每周一 9:00
- 是否需要推送到飞书、企业微信、Slack、邮箱或 Notion

## 不承诺什么

- 不承诺提升团队执行力
- 不承诺 GitHub API 永远稳定
- 不承诺历史任务能在没有标签规则的情况下完全自动分类
- 不做虚假 Star、刷量、垃圾营销或违规自动化

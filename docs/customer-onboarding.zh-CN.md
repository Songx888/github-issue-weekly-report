```text
6. 输出方式：

7. 是否需要客户汇报格式：

8. 其他要求：
```

## 部署前检查清单

- 仓库已经启用 Issues
- 团队有稳定使用标签
- 私有仓库准备好 GitHub token 或管理员协助
- 可以接受 GitHub Actions 每周自动运行
- 明确周报是内部同步还是客户汇报

## 验收标准

- 能手动触发一次 GitHub Actions
- 能生成一份 Markdown 周报
- 完成、进行中、阻塞分类符合客户标签规则
- 客户知道后续如何调整配置

# GitHub 周报工具变现方案

## 项目定位

这是一个面向小团队、外包团队、远程协作团队和开源项目维护者的 GitHub Issues/PR 自动周报工具。

免费仓库负责展示能力和建立信任，收入来自部署、接入、模板定制和维护服务。

## 收费设计

| 服务 | 价格 | 交付 |
| --- | ---: | --- |
| 快速部署 | 99 元/次 | 帮客户配置仓库、密钥和 GitHub Actions |
| IM 接入 | 199 元/次 | 接入飞书、企业微信、Slack 或邮件 |
| 模板定制 | 399 元/次 | 按客户汇报格式定制 Markdown 周报 |
| 月度维护 | 699 元/月 | 每周检查工作流，调整标签和规则 |
| 多仓库汇总 | 999 元/月 | 多个仓库汇总成一份客户/团队周报 |

## 日赚 100 元路径

- 3 个 999 元/月客户，月收入 2997 元，约等于每天 100 元。
- 5 个 699 元/月客户，月收入 3495 元，约等于每天 116 元。
- 每周 8 单 99 元部署，周收入 792 元，约等于每天 113 元。

## 获客话术

```text
你好，我看到你们项目主要用 GitHub Issues/PR 管理任务。
我做了一个小工具，可以自动生成每周项目周报，适合给团队或客户同步进度。
我可以免费帮你们基于现有 Issues 跑一份样例，如果觉得有用，再考虑是否部署。
```

## 7 天启动计划

1. 第 1 天：完善 README，录制 1 分钟演示 GIF 或截图。
2. 第 2 天：找 30 个 Issues 活跃但没有周报自动化的小型仓库。
3. 第 3 天：给 10 个仓库发 Issue 或联系维护者，提供免费样例。
4. 第 4 天：把反馈整理成 2 个典型案例。
5. 第 5 天：在掘金、V2EX、知乎发文章。
6. 第 6 天：把第一个免费样例转成 99 元部署服务。
7. 第 7 天：把部署客户升级为 699 元/月维护服务。

## 交付边界

不要承诺一定提升团队效率，也不要承诺 GitHub Actions 永远不失败。

可承诺内容：

- 正确配置仓库和密钥
- 按客户标签规则生成周报
- 提供一次部署说明
- 月度维护客户提供异常排查和规则调整

不可承诺内容：

- 保证客户团队执行流程变好
- 保证 GitHub API 永远可用
- 保证所有历史 Issues 都能完美归类
